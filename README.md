# CYV-CLI

**CYV-CLI** is a lightweight Python-based CLI tool for optimizing your Roblox client’s FPS and graphics settings. It modifies local configuration files to improve performance without affecting gameplay, bypassing anti-cheat, or modifying memory. Safe, simple, and user-friendly.  

---

## 🔹 Features

- Automatically detects your Roblox installation (supports **Roblox**, **Bloxstrap**, and **Fishstrap** launchers)  
- Applies FPS optimization presets via **FFlags**  
- Adjusts graphics and texture settings for smoother gameplay  
- Fully client-side: **No memory edits, no injections, no automation**  
- Creates a structured local folder in `%APPDATA%\cyv-cli` with:  
  - `func/` – Python modules like `fflags.py`  
  - `icons/` – Images and assets  
  - `config.ini` – CLI configuration  
- Safe backup system for all edited Roblox configuration files
